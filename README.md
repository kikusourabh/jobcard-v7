# Jewellery Job Card Generator

A small Node.js + Express web app that fills in a jewellery job card and produces it as a
**105 × 150 mm PDF**. You can upload the design and diamond-details images, crop them, auto-generate
the P no by category, re-open and edit a PDF you made earlier, and merge several PDFs into one.

## Features

- **Job card PDF** at exactly 105 × 150 mm: header details, instruction box, process table, repairing
  columns, CTG block and the Diamond / Packet No grid (the grids are left blank for handwriting).
- **Image uploads** for the design image (top left) and the diamond details / sieve table image (top right).
  PNG, JPG and WebP are accepted; images are auto-rotated and fitted without stretching.
- **Crop tool** for both images: drag on the preview to select an area. The design crop can replace the
  design image, be added under the diamond details image, or both.
- **Category and auto P no**: pick a category and the P no is generated as a prefix plus 3 random digits
  (for example `NK861`). Used numbers are remembered so a P no is never issued twice.
- **File name**: choose the name of the downloaded PDF (defaults to the P no).
- **Edit an existing PDF**: upload a PDF made by this app, change anything, and generate a new one.
- **Merge PDFs**: combine any number of PDFs into one, with reordering.

## Requirements

- Node.js 18 or newer
- npm

## Install and run

```bash
npm install
npm start
```

Open http://localhost:3000. To use another port: `PORT=8080 npm start`.

## How to use

### Create a job card
1. Optionally upload the **design image** and the **diamond details image**, and drag on a preview to crop it.
2. Choose a **Category**. The **P no** fills in automatically. Click **Next** for a new number, or type your own.
3. Fill in the other fields (names, dates, karat, color, size, Apx WTG, and so on) and the instruction text.
4. Optionally type a **File name**.
5. Click **Generate PDF**. It opens in a new tab and downloads.

### Crop options (design image)
After you drag a crop on the design image, a dropdown appears:

| Option | Result |
| --- | --- |
| Use crop as design image | The crop replaces the design in the top-left box |
| Add crop to diamond details image | The crop is stacked under the diamond table in the top-right box |
| Both | Both of the above |

The diamond details image has its own crop, which replaces that image. **Clear crop** removes a selection.

### Categories and P no prefixes

| Category | Prefix |
| --- | --- |
| Set | SET |
| Ring | RN |
| Penden | PN |
| Earing | ER |
| Bangal | BN |
| Bracelet | BR |
| Nosepin | NP |
| Necklace | NK |

The P no is `prefix + Math.random().toString().substring(2, 5)`. If every 3-digit number for a prefix
is already used, it moves to 4 digits. Issued numbers are stored in `data/pnos.json` (created
automatically; delete it to reset). A P no you type yourself is kept as typed and also recorded.

### Edit an existing PDF
Every generated PDF carries its own data (the field values and the two images) as PDF attachments.
Upload one in **Edit an existing job card** and the form is filled back in, including the P no and
file name. Change what you need and click **Generate PDF** to get a new file. The old PDF is not modified.

- Only PDFs generated by this app (after the edit feature was added) can be edited. Other PDFs show a message.
- Images come back as they were printed. A cropped design returns as the cropped version, not the original photo.
- A merged PDF cannot be edited. Edit the individual cards first, then merge.

### Merge PDFs
Add two or more PDF files (you can add more than once), reorder them with the arrows, remove any with ✕,
optionally set a merged file name, and click **Merge PDFs**. Pages keep their original size.
This works on any PDFs, not only job cards.

## API

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/api/categories` | List of category names |
| GET | `/api/gen-pno?category=Ring` | Suggest the next P no for a category (not reserved until a PDF is generated) |
| POST | `/api/pdf` | Generate a job card (multipart form) and return the PDF |
| POST | `/api/import-pdf` | Read back the fields and images embedded in a generated PDF (field `pdf`) |
| POST | `/api/merge` | Merge PDFs (repeated field `pdfs`, optional `fileName`) |

`POST /api/pdf` accepts these form fields: `category`, `pno`, `fileName`, `cname`, `odate`, `ddate`,
`karat`, `color`, `size`, `apxWtg`, `cadFile`, `quantity`, `rpt`, `casting`, `instruction`, files
`designImage` and `diamondImage`, and crop values `cropX`, `cropY`, `cropW`, `cropH`, `cropMode`
(design image) and `dcropX`, `dcropY`, `dcropW`, `dcropH` (diamond image). Crop values are fractions
from 0 to 1 of the image width and height. If `pno` is blank it is generated from `category`.

## Project structure

```
jobcard/
  server.js          Express server, uploads, P no, crop/merge/import logic
  pdf.js             Draws the 105 x 150 mm job card (PDFKit) and embeds the editable data
  public/index.html  The web form
  data/pnos.json     Issued P nos (created automatically)
  package.json
```

## Customising

- **Categories and prefixes**: edit the `CATEGORIES` object near the top of `server.js`.
- **Printed labels** (including the original spellings "quntity", "Daimond", "Reparing"): edit the text in `pdf.js`.
- **Layout**: sizes are in millimetres in `pdf.js`. For example `imgH` sets the image height, and the column
  widths `cw`, `pw` and `rw` set the header and table columns.
- **Limits**: uploads are capped at 15 MB per file, and up to 100 PDFs per merge (see the `multer` settings in `server.js`).

## Libraries

[Express](https://expressjs.com), [Multer](https://github.com/expressjs/multer) (uploads),
[PDFKit](https://pdfkit.org) (drawing the PDF), [sharp](https://sharp.pixelplumbing.com) (image processing),
[pdf-lib](https://pdf-lib.js.org) (reading embedded data and merging).
